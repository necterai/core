Install

Add detection to any website. Visitors show up under Sessions within a few seconds.

Add one script tag

Paste this into the <head> of every page, as high as you can. It works on any stack: plain HTML, WordPress, Shopify, Webflow, Next.js, or a tag manager.

This address only works on this computer. To use it on a public site, or to let a cloud agent reach it, run ngrok http and open this dashboard from the https address it prints. The snippet then updates itself.

Or put it in front of a site, with no code changes

Proxy mode serves an existing site through necter, adds the script to every page and also catches agents that never run JavaScript, such as fetch tools and crawlers.

corepack pnpm collector --upstream https://example.com

Or test on any page you visit

Drag this to your bookmarks bar, open any website and click it. It loads detection into that page only, for you. Sites with a strict content security policy will refuse it.

necter test
