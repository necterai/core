# Security policy

Necter is a security product, so two kinds of report matter to us:

- **Vulnerabilities in Necter itself** (for example a way to make the server SDK crash, leak data or run code).
- **Detection bypasses** (a way for an agent to read as human, or to pass as a verified provider it isn't).

Please report both privately, not in public issues: use [GitHub's private vulnerability reporting](https://github.com/necterai/core/security/advisories/new) for this repository.

Include what you did, what you expected and what happened, and the versions involved. We'll acknowledge within three working days and keep you updated until it's fixed. We're happy to credit you in the release notes.

Only the latest release receives security fixes while Necter is at 0.x.
